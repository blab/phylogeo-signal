## Scripts to reproduce analyses

### Assortativity parameters estimates
- [get_proba_stays_within_the_same_age_group.R](https://github.com/blab/phylogeo-signal/blob/main/scripts/get_proba_stays_within_the_same_age_group.R) contains scripts to estimate assortativity parameters for age mixing.
- [get_proba_stays_within_the_same_region.R](https://github.com/blab/phylogeo-signal/blob/main/scripts/get_proba_stays_within_the_same_region.R) contains scripts to estimate assortativity parameters for spatial mixing.
- [utils_contact_mat.R](https://github.com/blab/phylogeo-signal/blob/main/scripts/utils_contact_mat.R)
- [utils_connectivity.R](https://github.com/blab/phylogeo-signal/blob/main/scripts/utils_connectivity.R)

### Confusion matrix analysis
- [get_matrix_param_across_pathogens.R](https://github.com/blab/phylogeo-signal/blob/main/scripts/get_matrix_param_across_pathogens.R) enables reproducing the confusion matrix parameters computations used in Figure 3 (for the specific set of real-life pathogens detailed in the manuscript).
- [get_matrix_param_across_parameter_space.R](https://github.com/blab/phylogeo-signal/blob/main/scripts/get_matrix_param_across_parameter_space.R) enables reproducing the confusion matrix parameters computations used in Figure 4 (broadly exploring combinations of $p$ and $\omega$)
- [utils_sens_spec.R](https://github.com/blab/phylogeo-signal/blob/main/scripts/utils_sens_spec.R) contains functions implementing the confusion matrix parameter calculations.
